## 分发和模板配置

从运行版本导出的 [微观形貌 JSON](./examples/fiber-microscopy-v2.json) 和
[纸浆 JSON](./examples/paper-fiber-v2.json) 包含 Python 全文、参数、表单及模板规则，
不含本地凭据 ID、目录路径或 Worker 身份。依赖使用兼容版本范围，发布时冻结精确实现。
接收端安装当前适配包和模板后，只需绑定资源即可导入运行；不依赖旧流程或数据库规则。

微观形貌绑定四个目录：`electron_microscopy_records`（图片）、`execution_templates`
（模板）、`execution_staging`（生成文件）、`report_upload_images`（目标共享目录），
以及一个检务凭据槽 `inspection`。纸浆只需原始 Excel 目录与检务凭据。
目录设置中的共享地址用于返回可复制的 UNC 路径；Windows 暂存根必须与容器读写同一目录。

在“生成带图片的原始记录”配置模板 `original`、字段映射、图片范围 `A4:L32` 和打印范围
`$A$1:$L$37`。在“生成检务登记工作簿”配置键为 `1/2/3/5/6/7/10` 的模板集合；
可以选择安装模板目录，也可选择已配置的局域网共享模板目录，发布冻结引用和 SHA-256。
登记采集字段由配置映射到 `BI7/BK7/BI8…BI13`，无需改应用代码。

模板表位于“显微 · 组装字段和路径”的 `templates` 输入；每项保留目标检务模板名和映射
摘要。允许选图数量来自“显微 · 匹配项目和图片”的 `template_counts` 输入。增加或删除
图片数量时同步修改这两处及登记工作簿模板集合。目标共享子目录、文件名、项目匹配和
判定规则都可在对应 Python 节点及其输入参数中修改。远端新模板须先在检务系统配置，
映射摘要对应其实际采集字段；单纯更换本地排版不等于改变远端采集协议。
