# P3 原生领域节点与本地步骤迁移

日期：2026-09-17。基线：`7f5ff71`（电镜、纸纤维共享服务与直接 API）。本批把已有服务接入原生工作流，继续复用同一套领域逻辑；没有新增数据库表、队列、批准步骤或通用渲染框架。

## 交付内容

新增一个 `textile.domain-records@1.0.0` Pack，包含四个节点：

| NodeSpec | 输入与行为 |
| --- | --- |
| `microscopy.image_candidates@1` | 按检验编号查询显微图片，保留微观形貌/横截面领域规则，输出可直接进入 `human.select` 的候选 |
| `paper_fiber.find_records@1` | 查询 `.xls/.xlsx`，读取 W32/M32 及任务缓存，输出复用现有定性结果卡片的候选 |
| `microscopy.original_record.render@1` | 接收已选图片、样品名和确认后的判定字段，生成原始记录并注册制品 |
| `microscopy.check_record.render@1` | 接收图片数量和确认后的记录字段，生成供旧采集器读取的登记工作簿；可承接原始记录的模板绑定 |

查询绑定 `root_slot` 和 `rule_slot`，生成节点绑定来源/暂存根目录，支持部署时改为其他本地根。原生查询使用发布绑定的规则版本，规则已修改时提示重新绑定发布；旧节点保留原有规则解析行为。

渲染只接收已确认字段，不重复查询任务单，不同时要求图片 ID 和另一份图片列表。原始记录复用已有图片排版/重读服务；登记工作簿复用 BIFF 写入服务；两者复用同请求制品。`check_item_name` 可从旧项目映射传入，省略时使用记录家族的固定模板名称；任意名称不会被悄悄改成模板名称，原模板的业务约束保持。

`human.select` 图片使用已有图片选择器，支持缩略图、大图与稳定 ID 提交；纸纤维使用已有定性结果卡片。唯一候选可自动完成，多候选只需选择一次。目录按 v2 副作用声明展示本地写入流程。

## 示例与迁移边界

- [显微原生示例](./examples/v2-microscopy-records-smoke.json)：填写编号和样品名称 → 查询/选图 → 自动生成两份工作簿 → 下载。显式使用“无需判定”的本地验收场景，不代替任务单业务判定或检务写入。
- [纸纤维原生示例](./examples/v2-paper-fiber-records-smoke.json)：查询 → 单份原始记录选择 → 返回定性结果。唯一候选自动完成。

两份 JSON 可使用既有 Release API 导入、绑定和发布，不自动安装或接替业务入口。显微示例至少需要 `enforced + p2_local_write`，纸纤维示例至少需要 `enforced + p2_human`；验证使用 `p2_publish`。原始记录生成仍要求 LibreOffice/UNO。

`target_profile=native_p3` 为以下流程增加本地步骤迁移：

| 来源 slug | 原生替换 | 状态 |
| --- | --- | --- |
| `electron-microscopy-gbt36422` | 图片查询、原始记录、登记工作簿 | `p3_partial` |
| `electron-cross-section-gbt36422` | 同上，保持横截面家族 | `p3_partial` |
| `paper-fiber-gbt4688-2020-qualitative` | 文件查询与结果读取 | `p3_partial` |

迁移保留连线、输出映射、来源证据、原草稿和历史版本。停放节点先排除，缺少必要字段/资源映射的步骤保留兼容实现；不会猜测输入。业务表单和外部操作仍列为待迁移项，预览仍返回 `publish_ready=false`，运行准入继续阻止未交付的外部链。完整候选保持 **6/9**，以上三条部分迁移不计入完整覆盖；迁移完成后仍需独立的发布与接替操作。
