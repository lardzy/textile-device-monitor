# P4 完整业务迁移（2026-09-20）

完整原生迁移候选已覆盖 9/9 条内置流程。三条新增完整候选为纤维微观形貌、横截面形状、纸纤维定性；`native_p4` 保留来源证据，生成新的 slug，不修改旧入口。

## 本批行为

- 一次选择、一次补齐登记信息；单一候选和已知完整输入自动继续。检测项目切换时只显示对应必填字段，沿用业务服务的判定、身份和模板约束。
- 新增 `inspection.record.prepare@1`、`human.form@2` 和 `inspection.record.validate@1`，业务字段由共享服务准备和校验，人工节点仅执行表单协议。
- 9 个 OperationSpec 均可通过通用 `external.operation@1` 调度；上传、复核和登记复用既有持久化队列及回执。直接 HTTP 提交目前支持通用登记和精确更正，文件/复核适配仍需要 Run 制品上下文，不宣称所有操作均支持无 Run 提交。
- 报告图片直接使用 `file.batch_place`；操作输入映射取代上游节点 ID 配置。读写根来自绑定，历史 v1 快照保留原有工作目录语义。
- 自定义人工步骤不会被静默丢弃；不能完整识别的图返回迁移阻塞项。
