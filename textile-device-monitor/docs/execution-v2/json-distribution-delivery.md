# JSON 工作流与独立适配器交付

> 2026-09-22 更新：旧业务流程、节点目录、迁移入口及兼容 Worker 工具已退役。本页保留历史规划/验收事实；当前实现与部署以[执行系统重置与纸浆交付](./paper-rebuild-delivery.md)为准。通用 JSON 分发、模板目录、独立适配器机制继续使用。

本轮沿用已经完成的 P2–P5 引擎，不增加队列或插件服务。按以下四批实施并提交。

| 批次 | 交付 | 验收重点 |
| --- | --- | --- |
| 1 | JSON 规则定义、运行快照、安装/共享模板目录 | 跨环境仅绑定资源；修改本地规则不改变已发布内容 |
| 2 | 数据转换、校验、Python 计算；业务映射配置化 | 同能力内的字段与规则变化只修改 JSON，保留文件底层实现 |
| 3 | Connector 统一服务入口、独立适配包发现 | API 与工作流共用契约、幂等和回执；新增包不改中心分派 |
| 4 | 配置体验与独立 JSON 样例、回放、回归 | 导出后在另一环境导入、执行、验证 |

模板随安装包发布到用户可访问目录，也可从已挂载局域网共享目录选择。JSON 携带逻辑目录、相对路径及内容摘要，不携带机器路径和模板二进制；本轮不实现 `.twr`。共享目录使用现有 StorageRoot/FileGateway。

Python 是受信任流程作者的纯计算节点，版本化输入输出约定、独立进程、受限模块与执行预算。外部系统调用仍由 Connector 承担。安装适配器是代码部署行为，JSON 不导入任意 Python 模块。

生产和真实检务写入验收单独记录；本地测试不能替代现场验收。阶段性提交不推送、不部署。

## 第四批交付

9 条业务流程保存为安装包内的独立 JSON（`backend/app/execution/v2/resources/workflows/`）。模板目录不再即时迁移数据库中的旧流程：即使旧流程不存在、已归档或已接替，仍可从模板新建。模板不自动关联旧流程；需要保留本地修改并接替旧入口时，继续使用迁移预览。

设计器只建议当前节点的上游变量，按输入类型筛选；Python 提供多行代码编辑。模板文件选择支持安装目录和挂载共享目录，JSON 记录逻辑目录、相对路径和摘要。账号设置从已安装适配器读取系统列表，新增适配器无需修改前端列表或凭据校验。模板目录初始化失败时标为不可用，不阻断登录或历史访问。

设计器编译默认生成兼容版本范围，省去实现摘要和 Connector 合同摘要的手工同步。NodeSpec 合同版本与摘要仍保留；`POST /api/execution/v2/designer/compile` 的 `exact: true` 可生成全部精确依赖。发布锁定实际 Pack、节点和 Connector 的版本及摘要，既有 Run 不随安装包变化。契约改变须增加版本；旧实现不可用会明确报错，不能静默改用新实现。

增加 `POST /api/execution/v2/designer/test`、设计器“运行离线样例”和 `tools/execution_v2_fixtures.py`。JSON 内的 fixtures 可直接验证纯计算或显式 Mock 的顺序流程；人工、文件、工作簿和 Connector 不会被真实调用。样例输出标记 Mock，报告断言实际值；缺少断言、缺少 Mock 或不支持的分支/并行图明确失败。整组执行预算 30 秒。这不是完整 Worker/Bridge 集成验收执行器，后者继续使用已有隔离环境测试。

适配器增加端到端节点运行、独立凭据、通用对账入口与精确旧版本缺失验证。普通写入继续自动提交；仅结果不明时进入对账。

## 使用方式

1. 在设计器选择业务模板，或使用 `docs/execution-v2/examples/v2-data-python-example.json` 从纯计算开始。
2. 用 `data.transform` 一次处理多步字段转换；复杂计算放在一个 `data.python` 节点。规则 slot 内嵌完整 `definition`；不要只传另一台机器上的规则名称。
3. 模板通过 `workbook.render` 配置选择。默认位于 `EXECUTION_TEMPLATE_ROOT` 或运行目录的 `templates/`；共享目录先在服务器挂载并登记 StorageRoot。接收环境只需绑定目录和自己的账号。
4. 运行 JSON 自带样例，准备发布，再导出 JSON 分发。独立适配器安装/更新步骤见 [SDK](adapter-sdk.md)。

可变字段、筛选、计算、业务参数和规则由 JSON 分发。Excel/UNO、图片解析及旧检务协议实现仍是安装能力；新增普通流程不需要发应用包。任意新模板版式优先使用通用渲染；原有复杂 XLS 图片排版保留领域渲染，不能声称已支持所有 Excel 格式。
