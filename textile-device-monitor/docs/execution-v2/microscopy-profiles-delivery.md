# 微观形貌业务方案与分组执行

实施日期：2026-09-29。当前为实施记录，完成与验证结果在各阶段补充。

## 设计

- 沿用 `fiber-microscopy-v2` 的 Workflow ID，显示名称改为“微观形貌”。
- 业务方案是流程 JSON 内的固定参数，包含明确的项目编号和方法组合、记录标题、模板对应关系、共享子目录、命名和表单默认规则。Python 完整随 JSON 分发；发布和运行沿用既有不可变快照。
- 首批方案为 `5103.5 / GB/T 36422-2018` 和 `5103.05 / 按客户要求`。样品识别是任务分组，不是业务方案。
- 设计器集中编辑方案，模板资源仍使用现有模板选择、目录绑定和发布摘要冻结。
- 分组选图输出明确的组和图片顺序；通用顺序批处理节点复用同一版本的现有 Run、Worker、操作队列和重试机制。已经成功的组不重复运行。
- 父运行与组运行关联持久化；运行时不读取可变业务规则表，不调用按业务名称隐藏的应用函数。

## 实施顺序

1. 方案配置、可视化管理、只读匹配预览和原方案回归。
2. 通用分组选图、同版本顺序执行、分组状态与失败恢复。
3. 模板及真实任务核对、隔离全链路验证、容器更新与重新发布。
