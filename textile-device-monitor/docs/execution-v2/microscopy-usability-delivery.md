## 使用变化

- 新生成的工作簿名称由 JSON 内的「显微 · 组装字段和路径」Python 节点提供，例如 `260221991-薄膜正面-微观形貌-原始记录.xls`、`260221991-薄膜正面-微观形貌-检务登记.xls`。空样品识别省略，文件名中不允许的字符替换为短横线。
- 上传服务通过目录、路径和摘要查找制品的可读名称，实际读取仍使用原存储路径和内容摘要。Writer 加上分配后的检验编号；制品名称已带源编号时先去掉这段前缀，避免编号重复。直接上传源文件的纸浆链路继续保留源文件名。
- 原始记录「微观形貌」工作表 E2 映射为所选任务项目的 `check_method`，与登记表的 I8 / BI8 使用同一值。客户要求项目为「按客户要求」，标准方法项目仍使用任务单中的标准方法；不在适配器中固定业务方法。
- 运行页顶部提供「文件与打印（数量）」按钮，在独立抽屉中下载本次及各分组已生成的文件；失败、等待和取消状态仍可下载已生成文件。制品页同时显示可读文件名和下载按钮，服务端复用已有权限和下载接口。
- 使用 Excel 打开下载文件后打印，无新增人工待办或打印确认节点。原始记录保存为一页宽、一页高，避免右侧日期和样品识别被挤到第二页。

## 通用能力与 JSON

`workbook.render@3` 增加可绑定上游的 `filename` 输入；未提供时沿用配置文件名。`image_layout.fit_to_pages` 可设置 `wide`、`tall`（纵向 0 表示不限制），本流程为 `{"wide":1,"tall":1}`。保存后重新打开 XLS，核对实际页数缩放属性。底层使用 LibreOffice [TablePageStyle](https://api.libreoffice.org/docs/idl/ref/servicecom_1_1sun_1_1star_1_1sheet_1_1TablePageStyle.html) 的横纵向页数设置。

## 2026-09-30 人工确定共用样品名称

微观形貌已发布 **v8**，纸浆为统一内核同步发布 **v13**。开始新的微观形貌运行后，在「填写样品名称并分组选图」这一个待办中选择或填写样品名称，再按各部位选图。名称初始为空；即使只有一个候选、一个分组或一张图片，也必须人工确定。已选候选仍可修改，不能用空白名称提交；保存草稿及刷新页面会保留名称和图片选择。

原始任务单名称完整显示供对照。JSON 中的「按样品识别准备分组」Python 节点先提供规范化后的完整名称，再按配置分隔符、标点、空白及括号提供简短候选，最多 50 个；候选只是建议，操作人可自行填写不在列表中的名称。候选规则、表单定义与代码均在 [可编辑微观形貌 JSON](./examples/fiber-microscopy-v2.json) 中，不依赖隐藏业务函数或数据库规则。

确认后，名称随分组输入冻结并用于每组原始记录的 B3。之后任务单刷新或业务方案默认值不能覆盖它；各组的样品识别、图片、判定和其他必要字段仍分别处理。需要补充字段时，共用名称显示为只读，避免各组无意改成不同名称。未增加独立审批步骤。

通用 `human.group_select@2` 接收上游 `form_schema`，将一次填写的 `form_data` 与分组选项一起返回并纳入选择摘要；前端复用现有 Schema 表单。v1 契约保留供历史快照识别，新的节点目录优先使用 v2。内核 Pack 为 **2.13.0**；工作簿和检务 Pack、Windows Bridge/Writer 无须变更。
