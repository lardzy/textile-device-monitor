# Windows Bridge 1.3.0 现场操作

**首次部署只需三步：运行安装包，填写并检查参数，点击启用。** 此版沿用现有 Docker 后端和 Worker。Windows 机需已安装可用的旧检务客户端；Excel 登记还需已登录操作员的桌面 Excel。

1. **安装。** 对照随包的 `.sha256` 校验 EXE，双击以管理员身份安装。安装完成后打开 **开始 → Textile Execution Bridge → Bridge 配置中心**。
2. **填写和检查。** 选择「与服务端同机」或「指定服务器」，核对实际 API 协议及发布端口。执行暂存目录要和 Worker 指向同一份文件，跨机器请填 UNC 路径。填写 Bridge 令牌、检务与共享账号、密码，并确认 **Windows 任务账号** 是平时登录桌面使用 Excel 的操作员。纸浆目录、Oracle 和共享地址按本站实际值核对。点击「保存参数」「检查连接」。「已保存令牌」表示已填写；成功轮询后才会显示已认证。
3. **启用。** 打开「运行状态」，可先启用快照桥查任务，再启用写入桥。**启用写入桥后会领取已批准的真实任务。** 在窗口中确认各桥状态、应用的配置版本及日志。关闭窗口后任务继续运行，重启 Windows 后操作员需再次登录。

**日常修改。** 保存后，当前任务使用原参数收尾，再按新参数领取。空白密码框会保留已保存值。换机用「导出普通参数」「导入普通参数」，在目标机重新填写凭据和选择操作员。

**覆盖升级。** 从 1.2.x 首次升级应安排维护窗口，暂停新增和批准任务，确认已批准待领取、执行中及待回执的操作都已收尾，再运行安装包。旧配置自动迁移。从 1.3.0 起，安装器会等待当前任务收尾，自检成功后恢复之前启用的桥。显示「等待操作员登录」时，请用所选账号登录 Windows。

**异常或回退。** 「回执待核对」时在执行系统按原尝试核实旧检务结果，再处理原记录，避免重新上传。回退至 1.2.4 时先在窗口停用两桥，确认待办已收尾，保存本站 1.2.4 安装包及与该版匹配的旧配置。覆盖安装 1.2.4 后使用旧配置完成自检，再恢复原任务。首次升级后已变更的地址或口令需同步到旧配置。

**文件位置。** 程序在 `C:\TextileExecutionBridge`；机器配置在 `%ProgramData%\TextileExecutionBridge\config\settings.json`，备份与凭据密文随本机保留。任务日志在安装目录的 `work\logs`，可从窗口打开。
