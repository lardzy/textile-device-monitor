## 2. 当前暂定方向

| 编号 | 暂定方向 | 原因 |
|---|---|---|
| P-001 | 流程编辑器与检验员执行工作台分开 | 普通用户不应面对技术 DAG |
| P-002 | 人工交互建模为持久化人工任务，不把“弹窗”写成节点语义 | 支持跨人、跨天、刷新和审计 |
| P-003 | 主单是本次运行中的角色，不是文件池全局标记 | 避免并发污染和历史歧义 |
| P-004 | Excel 合并在副本上执行 | 保护原始记录 |
| P-005 | 文件在节点间以 `FileArtifact` 传递 | 支持路径安全、版本和血缘 |
| P-006 | 7 天和 6 个是默认查询/UI 限制，不是永久索引硬限制 | 支持复检、延期和历史补录 |
| P-007 | 类型识别由路径提示 + 文件名 + 工作簿内容指纹共同判断 | 降低错模板风险 |
| P-008 | 第一条垂直切片暂不自动提交生产检务系统 | 先验证数据和恢复机制 |
| P-009 | 先借鉴 Dify，不立即 Fork | 领域、体量、升级和许可证风险 |
| P-010 | 需要 Windows Agent 执行 Excel/旧系统等本地能力 | Docker 服务端不适合直接控制桌面 |
| P-011 | 工作流发布版本不可变 | 保证审计和运行可重复 |
| P-012 | 外部写入具有 `needs_reconciliation` 状态 | 成功未知时不能盲目重试 |

## 3. P0 必须回答的问题

### 3.1 编号、样品和项目

1. 委托单号、检验编号、样品编号、项目编号分别是什么？
2. 它们是一对一、一对多还是多对多？
3. 文件名中的编号和 Excel 内部编号哪个是权威值？
4. 是否存在一个文件包含多个项目或多个样品？

### 3.2 文件和主单

5. 多份文件分别代表多人独立测试、多个组分、不同阶段还是不同模板？
6. 为什么需要主单？需要保留主单中的哪些格式、字段、图片或公式？
7. 默认主单能否按当前用户、完整度、模板版本或时间自动建议？
8. 是否允许两名用户同时处理同一检验编号？
9. 文件选择后被修改，业务上应该重新开始还是只重新核对？

### 3.3 Excel

10. 实际扩展名有哪些：`.xls`、`.xlsx`、`.xlsm`？
11. 是否包含 VBA、图片、隐藏工作表、命名区域、外部链接或保护？
12. 是否必须使用 Microsoft Excel，还是 WPS 也属于生产环境？
13. 质量比例的公式是否只有 Excel 中存在？有没有正式计算标准可结构化？
14. Excel 中的面积、根数、含量分别由谁写入？
15. 合并后上传的是副本还是必须替换某个原文件？

### 3.4 复核与第三人

16. 主检和复核结果在哪里产生、如何匹配到同一任务？
17. 阈值是绝对百分点差、相对误差还是其它公式？
18. 比较使用完整精度还是先四舍五入？
19. 多组分按每个组分比较，还是整体比较？
20. 一个组分超限时需要整项第三人测试吗？
21. 第三人结果出来后：取最接近两人平均、三人中位数还是人工裁定？
22. 不同项目是否使用不同规则？
23. 初检、复核和第三人是否必须是不同人员？
24. 复核长期没有提交时如何提醒、升级或转交？

### 3.5 最终结果和检务系统

25. “上传原始记录”和“录入报告结果”各自使用什么业务 ID 防重复？
26. 上传成功但前端超时后，能否查询是否已经成功？
27. 一项成功、另一项失败是否允许“部分完成”？
28. 正式录入最终结果前是否必须人工确认？
29. 由谁的外部账号执行最终提交：发起人、复核人还是当前处理人？
30. 结果写错后，旧/新系统的修订流程是什么？

### 3.6 图片归档

31. 哪些项目需要图片？
32. 共享目录路径、文件夹命名和文件命名规则是什么？
33. 同名文件覆盖、追加还是生成版本？
34. 图片是否需要压缩、重命名、排序或生成索引？
35. 图片发布失败是否阻止整单完成？
