# 11. 原始记录排版约束格式（可复用模板）

每个涉及"模板 Excel + 自动填格/插图"的项目，都按本格式登记约束，
避免只靠口头约定或上下文记忆。新项目首次接入时复制下面的模板填写，
验收结果追加到对应项目文档的"验证记录"一节。

## 约束登记模板

```text
项目/流程：<名称，含标准号与流程 slug>
模板资产：<templates/ 下的文件名 + SHA-256>
工作表 / 打印区域：<sheet 名> / <Excel 打印区域>
填写单元格：<单元格=内容来源，逐格列出；留空格位也要注明"刻意留空">
图片画布（无图项目写"无"）：
  原点：<锚定单元格左上角，Excel 实测 pt>
  尺寸：<宽 cm × 高 cm，1/100 mm 值>
  边界：左 ≥ <…>，右 ≤ <…>，上 ≥ <…>，下 ≤ <…>
  合并单元格：<相关合并区>
  间距：<图间外加间距，0 表示允许紧密排列>
  布局规则：<单图贴满/网格/居中 等>
环境依赖：
  字体：<模板使用的字体及容器挂载来源>
  锚点换算因子：<当前值 + 校准环境 + 校准日期>
验收方式：
  - 容器内 UNO 重读核对（几何、比例、重叠、打印区域）
  - Windows Excel COM 只读实测（边界、字号字体的绝对值）
  - Excel 导出 PDF 截图目视核对
```

## 已登记项目

### 电镜—纤维微观形貌 GB/T 36422-2018（electron-microscopy-gbt36422）

- 模板资产：`gbt36422-2018-microscopy-original-record-v1.xls`
  SHA-256 `d2b70e114cb85c89e4961ba2acb1b0cb451656f7a12b5dd5bdbacba1d50f88ba`
- 工作表 / 打印区域：`微观形貌` / `A1:L37`
- 填写单元格：B2=检验编号、B3=样品名称、L3=样品识别、B33=判定依据（仅判否时）、
  I34=判定（仅判否时）；I33、B34、B35 刻意留空；A4/G4 占位符"插入图片"
  在插图前清除。
- 图片画布：
  - 原点：A4 左上角 = (0 pt, 52.5 pt)（Excel COM 实测）
  - 尺寸：21.6 cm × 11.7 cm（`CANVAS_WIDTH=21600`、`CANVAS_HEIGHT=11700`，1/100 mm）
  - 边界：左缘 ≥ A4 左缘；右缘 ≤ A4 左缘 + 21.6 cm；上缘 ≥ A4 上缘；
    下缘 ≤ A4 上缘 + 11.7 cm；BIFF 锚点量化尾差约 ±0.2 mm 可接受
  - 合并单元格：A4:F32、G4:L32
  - 间距：0（紧密排列；网格单元内为保宽高比居中的空白不算外加间距）
  - 布局规则：1～10 张等比例最大化网格；单图贴满至少一条边并居中；
    不裁剪、不拉伸、不重叠
- 环境依赖：
  - 字体：宋体（SimSun），挂载见
    `.tmp/execution-system-local-runtime/docker-compose.local.yml` 与 README；
    缺失时 LO 替换为 DejaVu/Arial 且列宽度量失真
  - 锚点换算因子 `MICROSCOPY_BIFF_EXCEL_X_SCALE`：当前 1.0
    （2026-08-07 于 SimSun 环境校准）；无宋体环境下 Excel 横向读窄，
    旧校准值 1.2745，环境变化必须重新校准
- 验收记录：见 `09_电镜纤维微观形貌首版.md` 第 9.3 节
  （1/2/3/5/6/7/10 图 Excel COM 实测 + PDF 截图）
